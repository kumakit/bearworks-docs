私自身、ライターとして日常的に様々な生成AIを比較・活用しており、普段は [Claude](https://search.yahoo.co.jp/search?ei=UTF-8&rkf=1&slfr=1&qrw=0&p=Claude&fr=link_kw_nws_direct&fr2=cid_d8f3c5149ddbf0039a6ddb997fb9de4d19dd5776) を使うことが多いのですが、この機能があるという理由でChatGPTに戻ってきてしまうほどです。長らくこの機能を使ってきましたが、その学習体験は本当に素晴らしいと感じています。  
  
しかし、小テストや期末試験の準備を本格的に進めたいとなると、少し話が変わってきます。ただStudy Modeを起動しただけで、ChatGPTがたちまち優秀な家庭教師になってくれるとは限りません。  
  
より良い学びを得るためには、AIの真の能力を最大限に引き出すための計画的な [プロンプト](https://search.yahoo.co.jp/search?ei=UTF-8&rkf=1&slfr=1&qrw=0&p=%E3%83%97%E3%83%AD%E3%83%B3%E3%83%97%E3%83%88&fr=link_kw_nws_direct&fr2=cid_d8f3c5149ddbf0039a6ddb997fb9de4d19dd5776) が必要です。学習者の個性がひとりひとり違うように、学習方法も1つとして同じものはないからです。  
  
自分に合ったアプローチを見つけることで、学びのプロセスはぐっと前向きなものになります。

## 毎回のセッション前の「セットアップ用プロンプト」

何も前提知識を与えないと、ChatGPTは当たり障りのない一般的な指導になりがちで、実際にはあまり役立ちません。私自身もその状況にしばらく悩まされていたため、今では毎回学習セッションをはじめる前に、必ずセットアップ用のプロンプトを入力するようにしています。  
  
このプロンプトは、自分が今どの学習段階にいて、何を重要視しているかをAIに伝える役割を果たします。その結果、そのあとに質問をした際、ChatGPTは何を達成すべきかを明確に理解してくれるようになるのです。  
  
当たり障りのない回答を防ぐためには、以下の文が効果を発揮します。  
  
@Study ［科目やトピック］の学習を手伝ってください。私の現在のレベルは［初心者 / 中級者 / 上級者］で、目標は［試験準備 / 業務スキルの向上 / 単に正しく理解すること］です。説明する際は、必ず［例え話 / 段階的な手順の解説 / 現実世界の具体例］を用いてください。時々クイズを出し、これまでに学習した内容を記録し、間違えた場合はその理由を教えてください。まずは［具体的な概念や質問］からはじめてください。  
  
このプロンプトを使うと、一般的な出力ではなく、常に自分の現状にしっかりと寄り添った回答が得られます。後述するほかのプロンプトを試す前に、まずはここからはじめてみるのも1つの手です。
