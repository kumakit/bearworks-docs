## A. 読みたくなるタイトル3案

### 案1：疑問・意外性を重視
* **タイトル**
  **「群間と群内って、粒度が違うのに足していいの？」から紐解く分散分析 ― p<0.05でも効果量2%になる理由**
* **狙い**
  著者が統計検定2級の学習中に実際に抱いた「群間のばらつき（グループ平均同士の差）と群内のばらつき（個人の差）は粒度が違うのに、なぜ混ぜて『全体のばらつき』と呼べるのか？」という素直かつ本質的な疑問をそのままフックにし、計算構造の謎解きから「有意差と効果量のズレ」へと自然に導く。
* **読者が興味を持つ理由**
  分散分析の公式（$SS_{\text{全体}} = SS_{\text{群間}} + SS_{\text{群内}}$）を暗記して計算問題は解けるものの、「なぜグループ単位の話と個人単位の話が足し算できるのか」にモヤモヤした経験を持つ学習者は多い。教科書の天下り的な説明では飛ばされがちな「粒度」という切り口に新鮮さを感じ、自分の言葉で腑に落ちる体験を期待して読みたくなる。

### 案2：読者の共感を重視
* **タイトル**
  **「有意差が出たのに効果は2%？」― F値・p値・イータ二乗（$\eta^2$）で迷子にならない分散分析の読み方**
* **狙い**
  「計算はできるのに、出てきた複数の指標（$F$値、$p$値、$\eta^2$）をどう結びつけて解釈すればいいか分からない」という学習者・実務初学者共通の悩みに寄り添う。
* **読者が興味を持つ理由**
  「$p = 0.0498$ で有意！」と喜んだ直後に「$\eta^2 = 0.02$（2%）」という数字を見て「結局この施策は効いているの？効いていないの？」と立ち止まってしまう状況は、統計検定2級の受験者にも実務の分析担当者にも「あるある」と共感されやすい。

### 案3：実務への応用を重視
* **タイトル**
  **「p=0.0498だから広告を全面変更！」が危ない理由 ― A/B/Cテストで誤判断しないためのF値・p値・効果量（$\eta^2$）**
* **狙い**
  Web広告デザイン（A/B/C 各100人・計300人）の閲覧時間比較という具体的なビジネスシーンを前面に出し、「統計的に有意＝すぐ採用」という実務で頻発する意思決定ミスに警鐘を鳴らす。
* **読者が興味を持つ理由**
  業務で効果検証に関わる読者にとって、「有意差が出た施策をそのまま本番導入して失敗するリスク」は切実な関心事である。「なぜ $p < 0.05$ だけでは判断できないのか」「代わりに何を見るべきか」という実務上の判断基準を持ち帰れる記事として強く惹きつけられる。

### 編集者として最もおすすめするタイトル
* **推奨案：案1**
  **「群間と群内って、粒度が違うのに足していいの？」から紐解く分散分析 ― p<0.05でも効果量2%になる理由**
* **選んだ理由**
  「有意差と効果量の違い」を解説する記事はWeb上に多数存在するが、**「群間と群内は粒度が違うのに、なぜ足して全体のばらつきと呼べるのか？」という著者自身の学習時の引っかかり**から出発して「平方和（$SS$）の足し算」と「平均平方（$MS$）の割り算」の役割分担を解き明かし、そこから「なぜ $F \approx 3.03$（有意）と $\eta^2 = 2\%$ が同時に成り立つのか」へつなげる構成は、本記事にしかない最大の独自性だからである。また、既存サイトの「分析の落とし穴」シリーズ（『数字は正しいのに結論が逆転？ シンプソンのパラドックス』など）が持つ「素朴な違和感から入る謎解きトーン」とも相性が良い。

## B. 記事の中心となる疑問

### 中心となる問い
> **「なぜ『群間と群内のばらつき』は足し算できるのに、『平均平方（$MS$）』は足し算できないのか？ そして、同じ1つの分散分析表から『統計的に有意（$p \approx 0.0498$）』と『効果はわずか2%（$\eta^2 = 0.02$）』という一見矛盾する2つの結論が同時に生まれるのはなぜか？」**

### なぜ、その疑問が面白いのか
分散分析（ANOVA）を学ぶとき、多くの人は「平方和 $SS$ → 自由度 $df$ で割って平均平方 $MS$ → $MS$ の比で $F$値」という**計算手順（レシピ）**として暗記する。しかし、同じ分散分析表の「タテの足し算（$SS$ の内訳）」と「ヨコの割り算からの比率（$MS$ の比＝$F$値）」が、**まったく異なる2つの問い**に答えていることには気づきにくい。
「群間と群内の粒度の違い」という著者の素朴な疑問を突破口にすると、「なぜ $SS$ は足せて $MS$ は足せないのか」という構造が氷解し、そのまま「なぜ $p < 0.05$ なのに $\eta^2 = 2\%$ にしかならないのか」という実務上の罠まで一本の線でつながる面白さがある。

### 読者は最初にどう考えそうか
1. **粒度への違和感・誤解**：「群間のばらつき」は3つのグループ平均（3個の数）のばらつき、「群内のばらつき」は300人それぞれのばらつきに見えるため、「3個の話と300人の話をそのまま足すのはおかしいのではないか？（あるいは、平均平方 $MS$ も足したら全体になるのではないか？）」と混乱する。
2. **有意差と効果量の混同**：「$p = 0.0498 < 0.05$ で統計的に有意だった」と聞けば、「広告デザインによって閲覧時間に大きな差が出た（だから全面変更すべきだ）」と直感的に考えてしまう。また、「$\eta^2 = 2\%$」と聞くと「閲覧時間が2%伸びた」「成功確率が2%」といった誤った読み替えをしてしまいやすい。

### 記事を読むことで、どのように理解が変わるのか
* **読む前**：「分散分析表は $F$値と $p$値を出すための途中計算の表」「$\eta^2$ は追加で覚える別の公式」というバラバラな暗記状態。
* **読んだ後**：
  * **粒度の謎が解ける**：群間平方和（$SS_{\text{群間}}$）も「各群平均と全体平均の差の二乗」に**群の人数（各100人）を掛けて300人分の重み（個票の単位）に揃えている**からこそ、群内平方和（$SS_{\text{群内}}$）と対等に足し算して全体平方和（$SS_{\text{全体}} = 10,000$）に分解できると納得できる。
  * **指標の役割が整理される**：
    * **$\eta^2$（イータ二乗）** は「足し算の世界（$SS$）」の指標であり、**「全体のばらつき（10,000）のうち、群間の違い（200）が何割を占めるか（＝2%）」**という**構成比**を見ている。
    * **$F$値** は「1自由度あたりに換算した割り算の世界（$MS = SS / df$）」の指標であり、**「群間の1自由度あたりのばらつき（$100$）は、群内の1自由度あたりのランダムなばらつき（約$33.0$）の何倍か（$\approx 3.03$倍）」**という**S/N比（シグナル対ノイズ比）**を見ている。
  * だから「全体の2%しか説明していなくても、人数（自由度297）が多くて1自由度あたりのノイズが小さければ、3倍以上の差として『統計的に有意』になり得る」というカラクリが腑に落ちる。

## C. 読者が驚く発見

### 発見1：「群間のばらつき」も実は300人全員分の合計として計算されている（だから足せるが、平均平方は足せない）
* **発見の内容**
  「群間」という言葉から「3つのグループ代表値だけの小さな計算」と思われがちだが、群間平方和（$SS_{\text{群間}} = 200$）は3つの群平均の差だけでなく**「×各群の人数（100人）」を掛けて300人全員分に引き伸ばした合計量**である。一方、自由度で割った平均平方（$MS_{\text{群間}} = 100$、$MS_{\text{群内}} \approx 33.0$）は「1自由度あたりの平均」に変換されているため、**足しても全体にはならない（$100 + 33.0 \neq 10,000$ であり、全体の平均平方 $10,000 / 299 \approx 33.4$ にもならない）**。
* **なぜ意外なのか**
  分散分析表では $SS$ の列も $df$ の列も「群間＋群内＝全体」とタテに足し算できるため、右隣の $MS$ の列もなんとなく同じ感覚で見てしまう。しかし、「合計量（$SS$）」と「1自由度あたりの密度・平均（$MS$）」では計算の粒度が根本的に切り替わっている。
* **統計学的な根拠**
  各個人のデータ $x_{ij}$ と全体平均 $\bar{x}$ の差は $(x_{ij} - \bar{x}) = (\bar{x}_i - \bar{x}) + (x_{ij} - \bar{x}_i)$ と分解でき、全員分を二乗して足し合わせると交差項が0になり、
  $$SS_{\text{全体}} = \sum_{i=1}^{a} n_i (\bar{x}_i - \bar{x})^2 + \sum_{i=1}^{a}\sum_{j=1}^{n_i} (x_{ij} - \bar{x}_i)^2 = SS_{\text{群間}} + SS_{\text{群内}}$$
  が厳密に成り立つ。ここで第1項に $n_i$（各群の人数）が掛かっているため、両者とも「300人分の平方の合計」という同じ粒度・単位で揃っている。対して $MS = SS / df$ は異なる分母（$df_{\text{群間}} = 2$ と $df_{\text{群内}} = 297$）で割った商であるため、加法性は成り立たない。
* **読者にとっての価値**
  著者がつまずいた「粒度が違うのに混ぜてよいのか？」という疑問が数学的・直感的に解消され、分散分析表のどこが「足せる量」でどこが「比べる量」なのかを一目で区別できるようになる。

### 発見2：「全体のばらつきの2%しか説明できない（$\eta^2 = 2\%$）」のに「約3倍の差（$F \approx 3.03$）で有意」が矛盾なく両立する
* **発見の内容**
  広告デザインの違いが閲覧時間の全平方和に占める割合はわずか **2%（$200 / 10,000$）** で、残り **98%（$9,800 / 10,000$）** は個人差などの残差である。それにもかかわらず、$F$値は **$3.03$** となり、5%水準で有意（$p \approx 0.0498$）と判定される。
* **なぜ意外なのか**
  直感的には「98%がノイズで、原因が2%しか占めていないなら、誤差に埋もれて有意差なんて出るはずがない」と感じる。しかし、その98%の残差平方和（$9,800$）は **297個の自由度** で薄く分け合っているのに対し、2%の群間平方和（$200$）はたった **2個の自由度** に集中しているため、1自由度あたり（$MS$）で比べると **$100 \div 33.0 \approx 3.03$倍** と逆転現象のような見た目になる。
* **統計学的な根拠**
  標本における効果量 $\eta^2 = \frac{SS_{\text{群間}}}{SS_{\text{全体}}}$ と $F = \frac{SS_{\text{群間}} / df_{\text{群間}}}{SS_{\text{群内}} / df_{\text{群内}}}$ の間には、
  $$\eta^2 = \frac{df_{\text{群間}} \cdot F}{df_{\text{群間}} \cdot F + df_{\text{群内}}}$$
  という一対一の関係がある。群内の自由度 $df_{\text{群内}}$（すなわちサンプルサイズ）が大きくなればなるほど、同じ $F \approx 3.03$（$p < 0.05$）であっても $\eta^2$ はいくらでも小さく（0に近く）なり得る。
* **読者にとっての価値**
  「サンプルサイズが大きいA/Bテストでは、実務上ほとんど意味のない微小な差でも $p < 0.05$ になりやすい」という有名な注意点を、「そういうものだ」という暗記ではなく、**自由度による割り算の仕組み**として自分の頭で理解できる。

### 発見3：「$\eta^2 = 2\%$」は「閲覧時間が2%伸びた」という意味ではまったくない
* **発見の内容**
  $\eta^2 = 0.02$（2%）という数字が出たとき、「広告を変えたら平均閲覧時間が2%増えた」「2%のユーザーに効果があった」と解釈するのはすべて誤りである。また、$p = 0.0498$ と $p = 0.0501$ の間に「効果の有無」の断崖絶壁があるわけでもない。
* **なぜ意外なのか**
  「効果量＝2%」とパーセント表示されると、日常感覚で「平均値の増加率（＋2%）」や「コンバージョン率の改善幅」と錯覚しやすい。また、分散分析表の集計値（$SS_{\text{群間}}=200, SS_{\text{群内}}=9,800$）だけでは、そもそも「A・B・Cのどの広告が何秒長かったのか（各群の平均値）」すら一意には決まらない。
* **統計学的な根拠**
  $\eta^2$ はあくまで「この標本における**平方和（偏差の二乗和）の割合**」であり、元の単位（秒）ではなく「秒の二乗」の比率である。さらに、標本から計算した $\eta^2$ は母集団における真の寄与率を過大評価しやすい性質（標本特有のばらつきを含む）があり、母集団で必ず2%になることを保証するものでもない。そして一元配置分散分析の $F$検定は「3群の母平均がすべて等しいか、少なくとも1つ異なるか」を見ているだけで、どの群がどれだけ優れているかは群平均の差（秒）や信頼区間を見なければ分からない。
* **読者にとっての価値**
  分析レポートで「有意差あり（$p < 0.05$）、効果量2%」という報告を見たときに、言葉のマジックに騙されず「で、実際に何秒伸びたの？ 導入コストに見合う差なの？」と冷静に問い返せる実務力が身につく。

## D. 記事の構成

公開記事（想定ファイル：`docs/anova-significance-effect-size-pitfall.md`）の見出し構成案です。同じ架空データ（Web広告デザインA/B/C 各100人・計300人の閲覧時間）を最初から最後まで一貫して使用します。

### 1. 導入クイズ：「p = 0.0498 で有意！」この広告、全面変更していい？
* **そのセクションで伝えること**
  Web広告デザイン A/B/C（各100人、計300人）の閲覧時間を比較した分散分析の結果表（$F \approx 3.03, p \approx 0.0498, \eta^2 = 0.02$）を最初に提示し、「有意水準5%をクリアしたから新デザインへ全面刷新しよう！という判断に潜む罠は何か？」と読者に問いかける（※学習用の架空データであることを冒頭のAdmonitionで明記）。
* **読者が感じる疑問や発見**
  「$p < 0.05$ なら統計的に差があると言えたはずでは？ なぜダメなの？」「一方で効果量 $\eta^2 = 2\%$ ってどういうこと？」と、2つの数字のギャップに好奇心が刺激される。
* **前後のセクションとのつながり**
  結論を急がず「判断の迷い」を共有したうえで、まずは基本となる $F$値と $p$値が何を測っているのかを次節で確認する導線を作る。

### 2. そもそも F値と p値は何を答えているのか？
* **そのセクションで伝えること**
  分散分析表から $F = MS_{\text{群間}} / MS_{\text{群内}} = 100 / 33.0 \approx 3.0306$ と $p \approx 0.0498$ が計算される流れを整理する。帰無仮説「3群の母平均はすべて等しい」の下で、自由度 $(2, 297)$ の $F$分布において $3.03$ 以上の値が出る右側確率が $p$値であることを解説し、「$p$値は帰無仮説が正しい確率ではない」「$p$が小さい＝効果が大きいではない」という基本を押さえる。
* **読者が感じる疑問や発見**
  計算手順は復習できるが、表を眺めるうちに「そもそも、なぜ『群間のばらつき（200）』と『群内のばらつき（9,800）』を足して『全体（10,000）』にしていいのか？」という疑問が浮かび上がる。
* **前後のセクションとのつながり**
  計算式の確認から一歩踏み込み、著者が学習中に最も引っかかった「粒度の疑問」を解決するメインパート（第3節）へ自然につなぐ。

### 3. 【核心の疑問】群間と群内は「粒度」が違うのに、なぜ足し算できるのか？
* **そのセクションで伝えること**
  「3つのグループの差（群間）」と「300人それぞれの個人差（群内）」は粒度が違うのに、なぜ $SS_{\text{全体}} = SS_{\text{群間}} + SS_{\text{群内}}$ と混ぜて呼べるのかを直感的に解き明かす。
  * 「個人のズレ（全体平均との差）＝ 所属グループ平均と全体平均の差 ＋ 個人と所属グループ平均の差」に分解できること。
  * 群間SSは単に3つの群平均を比べているだけでなく、**「×各群100人」を掛けて300人全員分の平方の単位に揃えている**から足せること。
  * 逆に、自由度で割った平均平方（$MS$）は「1自由度あたりの平均」に粒度を変換した後の値なので、**$MS_{\text{群間}} + MS_{\text{群内}}$ という足し算は無意味である**こと。
* **読者が感じる疑問や発見**
  「なるほど！ $SS$ は300人全員分の合計量に揃えているから足し算できて、$MS$ は自由度で割った1単位あたりの強さだから割り算（比）に使うのか！」という最大の「アハ体験」を得る。
* **前後のセクションとのつながり**
  「足し算の世界（$SS$）」と「割り算の世界（$MS$）」の違いが分かったところで、そこから生まれる2つの指標（$\eta^2$ と $F$値）の対比（第4節）へと進む。

### 4. 同じ表から「まったく別の問い」に答える：F値 vs イータ二乗（$\eta^2$）
* **そのセクションで伝えること**
  同じ分散分析表から計算される $F \approx 3.03$ と $\eta^2 = 2\%$ が、それぞれ何を分母にして何を答えているのかを比較表と図解で整理する。
  * **$F$値の問い**：「群間の1自由度あたりのばらつき（100）は、群内のランダムなばらつき（約33.0）と比べて何倍か？」（ノイズに対するシグナルの強さ）
  * **$\eta^2$ の問い**：「この標本の全体SS（10,000）のうち、広告デザインの違い（200）は何割を占めるか？」（全体のばらつきに占める構成比＝2%）
  * なぜ「残り98%が個人差（残差）なのに $p < 0.05$ になるのか」を、自由度（2 vs 297）の違いから種明かしする。
* **読者が感じる疑問や発見**
  「98%が群内のばらつきでも、297人で割ると1自由度あたりは33になり、2自由度で割った群間（100）の方が3倍大きくなるのか！」と、冒頭の矛盾が完全に解消される。また、「$\eta^2 = 2\%$ は閲覧時間が2%増えたという意味ではない」という重要な注意点を知る。
* **前後のセクションとのつながり**
  統計的なカラクリが解けたところで、冒頭の問い「では実務で広告を全面変更すべきか？」の意思決定（第5節）へ戻る。

### 5. 「有意差あり ≠ 大きな効果 ≠ 実務での価値」：現場でどう判断するか？

## E. 図表・グラフのアイデア

記事の理解と面白さを決定づける3つの図表案です（モバイル表示・ダークモード対応の軽量なSVGを想定）。

### 図表1：全体のばらつき（SS=10,000）の内訳 ―「2%の群間」と「98%の残差」
* **図表のタイトル**
  `図1：全平方和（SS=10,000）の内訳とイータ二乗（η² = 2%）の意味`
* **表現形式**
  100%積み上げ横棒グラフ ＋ 吹き出し注記（模式図併用）
* **何を可視化するのか**
  全体の平方和 $SS_{\text{全体}} = 10,000$（100%）のうち、広告デザインの違いによる群間平方和 $SS_{\text{群間}} = 200$ が左端のわずか **2%** にすぎず、残りの **98%（$SS_{\text{群内}} = 9,800$）** は同じ広告を見た人同士の個人差（残差）であることを視覚的な面積比で示す。
* **読者に伝えたい発見**
  「$p = 0.0498$ で有意！」という言葉だけ聞くと広告デザインが決定的な差を生んでいるように錯覚するが、ばらつき全体の構成比（$\eta^2$）で見ると98%は個人差であり、広告デザインの違いが説明している割合は2%にとどまるという視覚的なインパクト。
* **作成に必要なデータ**
  Issue記載の架空ANOVA集計値（$SS_{\text{群間}} = 200$, $SS_{\text{群内}} = 9,800$, $SS_{\text{全体}} = 10,000$）。生データ不要。
* **作成時に注意すべき統計的な問題**
  * グラフのすぐ近くに**「※ $\eta^2 = 2\%$ は『平均閲覧時間が2%増えた』でも『施策の成功率が2%』でもなく、この標本の平方和（ばらつき）に占める割合」**と明記し、増加率との混同を防ぐ。
  * 学習用の架空の分析結果であることをキャプションに明記する。

### 図表2：同じ分散分析表から分岐する「2つの計算ルート（足せるSS・比をとるMS）」と粒度の仕組み
* **図表のタイトル**
  `図2：なぜSSは足せてMSは足せないのか？ 分散分析表の2つのルート（η² と F値）`
* **表現形式**
  構造フロー図（2段構成の概念ダイアグラム）
* **何を可視化するのか**
  * **上段（粒度が揃う理由）**：「群間のズレ² × 100人 × 3群 ＝ 300人分の平方和（$SS_{\text{群間}}=200$）」と「個人のズレ² × 300人分 ＝ 300人分の平方和（$SS_{\text{群内}}=9,800$）」が、どちらも「300人分の合計量」という同じ粒度だからこそ合算して $SS_{\text{全体}}=10,000$ になり、その構成比が **$\eta^2 = 200 / 10,000 = 2\%$** になるルート（緑矢印）。
  * **下段（自由度で割るルート）**：$SS_{\text{群間}}=200$ を $df=2$ で割った **$MS_{\text{群間}}=100$** と、$SS_{\text{群内}}=9,800$ を $df=297$ で割った **$MS_{\text{群内}} \approx 33.0$** を比較し、その割り算（比）が **$F \approx 3.03$** になるルート（青矢印）。そして $MS$ の列には大きく「**✕ 足し算禁止（$100 + 33.0 \neq \text{全体}$）**」の警告バッジを配置する。
* **読者に伝えたい発見**
  「たった200しかなかった群間SSが、自由度2で割ると100になり、9,800もあった群内SSが自由度297で割ると約33.0に縮むため、1自由度あたりの比（$F$値）をとると約3倍に逆転する」という、**$\eta^2 = 2\%$ と $F \approx 3.03$ が両立するメカニズム**を一目で体感させる。
* **作成に必要なデータ**
  Issue記載の架空ANOVA表の数値（$SS$: 200 / 9,800 / 10,000、$df$: 2 / 297 / 299、$MS$: 100 / 約33.0、$F \approx 3.0306$、$\eta^2 = 2\%$）。生データ不要。
* **作成時に注意すべき統計的な問題**
  * 「群間SSは3つの数しか使っていない」という誤解を解くため、「×群の人数（$n=100$）」の重みが掛かっていることを図中に明示する。
  * $MS_{\text{全体}}$（$= 10,000 / 299 \approx 33.44$、不偏分散）は通常のANOVA表では空欄（`—`）にされる理由も「$MS_{\text{群間}} + MS_{\text{群内}}$ と一致せず誤解を招くため」と補足すると親切である。

### 図表3：自由度 (2, 297) の F分布における「p = 0.0498」のきわどさと、同じ集計値でも変わり得る群平均のイメージ
* **図表のタイトル**
  `図3：自由度(2, 297)のF分布と「p ≈ 0.0498（5%境界ギリギリ）」の位置`
* **表現形式**
  確率密度曲線（$F(2, 297)$ 分布のグラフ）＋ 5%棄却域の拡大インセット図
* **何を可視化するのか**
  自由度 $(2, 297)$ の $F$分布曲線を描き、5%水準の臨界値（$F_{0.05}(2, 297) \approx 3.0262$）と、今回の観測値 **$F \approx 3.0306$**（右側面積 $p \approx 0.0498$）が、肉眼ではほぼ重なるほどの僅差であることを拡大図付きで可視化する。
* **読者に伝えたい発見**
  「$p < 0.05$ で有意！」と白黒はっきりついたように見えても、実際には臨界値 $3.026$ に対して $3.031$ という紙一重の位置にあり、もしあとほんの少しばらつきが大きくて $F = 3.020$（$p \approx 0.0503$）だったら「有意差なし」になっていたという**二分思考（0.05の崖）の危うさ**を直感させる。
* **作成に必要なデータ**
  自由度 $(df_1 = 2, df_2 = 297)$ の $F$分布の理論確率密度関数（Pythonの `scipy.stats.f` 等で正確に算出可能）。
* **作成時に注意すべき統計的な問題**
  * 右裾の面積（$p \approx 0.0498$）は非常に細く潰れやすいため、右裾部分（$F = 2.5 \sim 4.5$ 付近）を虫眼鏡のように拡大したインセット（小窓）を添えるか、数値注記を明確に入れてスマホ画面でも判読できるようにする。
  * **※もし「3群のばらつきイメージ」を補助図として添える場合の注意**：Issueにある通り、ANOVA表の集計値（$SS_{\text{群間}}=200, SS_{\text{群内}}=9,800$）だけでは3群の具体的な平均値や個票は一意に復元できない（例えば全体平均が50秒だとしても、各群平均は約 $(-1.0, 0, +1.0)$ 秒の差になるだけで、どの群がA/B/Cかも決まらない）。したがって、個票や群平均の図を作る場合は「実測データではなく、$SS_{\text{群間}}=200, SS_{\text{群内}}=9,800$ を満たす無数の組み合わせのうちの1つの説明用シミュレーション例である」と厳密に区別・明記する必要がある。本企画では誤解を避けるため、図3は理論値だけで正確に描ける「$F$分布の境界可視化」を第1候補とする。

## 5. 最後に編集者としての提案

### ① この記事で最も面白くできそうな部分
**「群間と群内は粒度が違うのに、なぜ足せるのか？」という疑問と、「なぜ $p < 0.05$ なのに効果量が2%にしかならないのか？」という疑問が、実は『平方和（$SS$）と平均平方（$MS$）の変換』というたった1つの仕組みの裏表であると種明かしする瞬間（第3節〜第4節）**です。
多くの解説記事では「分散分析の仕組み」と「効果量の話」が別々のトピックとして語られますが、この記事企画では「足し算の世界（$SS \rightarrow \eta^2$）」と「自由度で割った割り算の世界（$MS \rightarrow F$値）」を対比させることで、2つの疑問が一気に氷解する快感を作れます。

### ② 一般的な統計解説記事との差別化ポイント
1. **「公式の天下り」ではなく「学習者のリアルな違和感（粒度）」から出発している点**：多くの記事が素通りする「なぜ $SS$ は足せて $MS$ は足せないのか」を正面から図解します。
2. **1つの架空データ（$SS = 200 / 9,800 / 10,000$, $df = 2 / 297 / 299$）を最後まで使い切る点**：途中で別の例に飛ばず、同じ表を角度を変えて読み解くことで、「同じ数字なのに見る指標によってまったく景色が変わる」ことを体感させます。
3. **「$\eta^2 = 2\%$ が意味しないこと」まで踏み込む誠実さ**：「効果量も見ましょう」で終わらず、「2%＝閲覧時間が2%伸びた、ではない」「分散分析表だけでは各群が何秒違うかすら分からない」という実務上の盲点まで明確に言語化します。

### ③ 記事の品質を高めるために、著者から追加で聞きたいこと
* **「実務セクション（第5節）で触れる意思決定の文脈」**：Web広告の閲覧時間を例にする際、著者の実務感覚として「閲覧時間が数秒伸びたとしても、デザイン改修コストやコンバージョン率（CVR）への影響を見ないといけない」といった具体的なエピソードや強調したい実務の視点があるか。
* **「数式の露出バランス」**：既存の『シンプソンのパラドックス』記事では本文の数式を最小限に抑えて図を主役にしていますが、今回の平方和分解（$SS_{\text{全体}} = SS_{\text{群間}} + SS_{\text{群内}}$）の数式は本文に出したいか、それとも折りたたみ（`??? info`）に収めたいか。

### ④ この企画の弱点や、執筆前に検証すべきこと
1. **「各群の平均値が何秒違うのか」を分散分析表だけからは語れないジレンマ（正確性と具体性のトレードオフ）**
   * **課題**：第5節で「実務では群平均の差（何秒違うか）を見よう」と伝える際、読者は当然「じゃあ、この広告A/B/Cは実際に何秒違ったの？」と知りたくなります。しかし、Issueにも明記されている通り、分散分析表（$SS_{\text{群間}}=200, n=100\times 3$）だけでは各群の平均値は一意に決まりません。
   * **執筆前の検証・対策**：計算上、各群100人（$n=100$）で $SS_{\text{群間}} = \sum_{i=1}^3 100 (\bar{x}_i - \bar{x})^2 = 200$ となるためには、$\sum_{i=1}^3 (\bar{x}_i - \bar{x})^2 = 2$ です。例えば3群の平均が等間隔なら、全体平均との差は **$-1.0\text{秒}, 0\text{秒}, +1.0\text{秒}$**（最大と最小の群の差がわずか **2秒**、一方で群内の標準偏差は $\sqrt{33.0} \approx 5.74\text{秒}$）という一例が計算できます。執筆時には、これを「実測値」として書くのではなく、**「たとえば3群の平均が等間隔だったと仮定すると、全体平均から±1秒（最大差2秒）しか違わない計算になる（個人差の標準偏差は約5.7秒もある）」**というように、「集計値と整合する理論上の具体例」として条件を明記して示すと、統計的な正確性を一切損なわずに読者の納得感を劇的に高められます。
2. **標本効果量 $\eta^2$ と母集団効果量（$\omega^2$ 等）の扱いの深さ**
   * **課題**：厳密には $\eta^2 = SS_{\text{群間}} / SS_{\text{全体}}$ は「この標本での平方和の割合」であり、母集団での寄与率としては過大評価バイアスがあります（自由度が小さいほど顕著）。しかし、ここでオメガ二乗（$\omega^2$）や偏イータ二乗（$\eta_p^2$）の公式まで広げすぎると、記事の焦点がぼやけて冗長になります。
   * **執筆前の検証・対策**：統計検定2級および本記事のスコープに合わせ、本文では $\eta^2$ に集中しつつ、注記（Admonition）で「$\eta^2$ はこの標本における割合であり、母集団で必ず2%になるという意味ではない（母集団の推定には $\omega^2$ などが使われることもある）」と1〜2文で正確に境界を引くのが最善です。
3. **数値の端数処理の統一（要確認・検算済み事項）**
   * $F = (200 / 2) / (9800 / 297) = 100 / (9800 / 297) = 29700 / 9800 \approx 3.030612$
   * 自由度 $(2, 297)$ の右側確率 $p \approx 0.04978 \rightarrow 0.0498$
