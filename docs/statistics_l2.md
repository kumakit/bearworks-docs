# 統計検定2級 学習用まとめ

## 1. 推測統計（各種分布）

### t分布 (Student's t-distribution)

t分布は、母分散が未知の正規分布に従う母集団から、小標本（標本サイズ $n$ が小さい）を抽出した際の標本平均の分布を扱う際によく利用されます。

**特徴:**
- 左右対称の釣鐘型（正規分布に似ている）。
- 正規分布よりも裾（テール）が厚い。
- 自由度 $df$ (degrees of freedom) というパラメータを持ち、$df$ が大きくなるほど標準正規分布 $N(0, 1)$ に近づきます。

**数式:**
自由度 $k$ のt分布の確率密度関数は以下の通りです。
$$
f(t) = \frac{\Gamma(\frac{k+1}{2})}{\sqrt{k\pi}\Gamma(\frac{k}{2})} \left(1 + \frac{t^2}{k}\right)^{-\frac{k+1}{2}}
$$

## 2. 記述統計

記述統計は、収集したデータの特性を要約・把握するための基礎手法です。各分野の詳細は個別ページを参照してください。

### [1変数記述統計](univariate-descriptive-statistics.md)
単一の変数からデータの傾向を掴む手法。
- **代表値**: 平均値、中央値（外れ値に強い）、最頻値
- **散布度**: 分散・不偏分散、標準偏差、範囲、四分位範囲 (IQR)、変動係数 (CV)
- **形状・指標**: 歪度（非対称性）、尖度（尖り具合）、ローレンツ曲線とジニ係数（不平等度）

👉 詳細な解説・数式は [1変数記述統計](univariate-descriptive-statistics.md) を参照。

### [2変数記述統計](bivariate-descriptive-statistics.md)
2つの変数間の関係性（相関や連関）を分析する手法。
- **量的データ（相関）**: 散布図、共分散、ピアソンの積率相関係数（$-1 \le r \le 1$）、スピアマンの順位相関係数
- **質的データ（連関）**: 分割表（クロス集計表）、カイ二乗統計量、クラメールの連関係数
- **単回帰分析**: 回帰直線（最小二乗法）、決定係数 ($R^2 = r^2$)

👉 詳細な解説・数式は [2変数記述統計](bivariate-descriptive-statistics.md) を参照。
