# 統計検定2級 学習用まとめ

## 1. 記述統計

手元のデータが持つ特徴を、数値やグラフで客観的に整理・要約するための基礎手法です。各分野の詳しい解説や計算式は、それぞれの個別ページにまとめています。

### [1変数記述統計](univariate-descriptive-statistics.md)
1つのデータ列（変数）に着目し、その分布の特徴や中心的な傾向を掴むための指標です。
- **代表値**: 平均値、中央値（外れ値に強いロバストな指標）、最頻値
- **散布度**: 標本分散・不偏分散、標準偏差、範囲、四分位範囲（IQR）、変動係数（CV）
- **形状・指標**: 歪度（左右の非対称性）、尖度（中心の尖り具合）、ローレンツ曲線とジニ係数（格差・不平等度）

👉 詳しい解説と計算式は [1変数記述統計](univariate-descriptive-statistics.md) をご覧ください。

### [2変数記述統計](bivariate-descriptive-statistics.md)
2つの変数の間にどのような関連があるかを捉える手法です。
- **量的データの関係（相関）**: 散布図、共分散、ピアソンの積率相関係数（$-1 \le r \le 1$）、スピアマンの順位相関係数
- **質的データの関係（連関）**: クロス集計表（分割表）、カイ二乗統計量、クラメールの連関係数
- **単回帰分析の基礎**: 回帰直線（最小二乗法によるあてはめ）、決定係数 ($R^2 = r^2$)

👉 詳しい解説と計算式は [2変数記述統計](bivariate-descriptive-statistics.md) をご覧ください。

### t分布 (Student's t-distribution)

母集団が正規分布に従っているものの「母分散が分からない」状況で、標本サイズ $n$ が小さいサンプルから標本平均を推測・検定する際によく使われる分布です。

**主な特徴:**
- 平均を中心とする左右対称の釣鐘型（標準正規分布によく似た形）。
- 正規分布に比べて裾（テール）が厚く、外れ値が出やすい。
- 自由度 $df$ (degrees of freedom) というパラメータを持ち、自由度が大きくなるほど標準正規分布 $N(0, 1)$ に限りなく近づく。

**数式（確率密度関数）:**
自由度 $k$ のt分布の確率密度関数は以下の通りです。
$$
f(t) = \frac{\Gamma(\frac{k+1}{2})}{\sqrt{k\pi}\Gamma(\frac{k}{2})} \left(1 + \frac{t^2}{k}\right)^{-\frac{k+1}{2}}
$$
