# 1変数記述統計

ひとつの変数（属性）に注目し、手元にあるデータの中心的な傾向やばらつき具合をわかりやすく要約する手法です。

## 代表値 (Central Tendency)
データ全体がどのあたりの値を中心に集まっているかを示す指標です。

- **平均値 ($\bar{x}$)**: 最も基本的な算術平均。すべての数値を足してデータ数で割った値。
    - *※試験では、売上成長率などの変化率に使われる「幾何平均」や、往復の平均速度などに使われる「調和平均」も出題されます。*
- **中央値 (Median)**: データを小さい順に並べたとき、ちょうど中央に位置する値。極端に大きい・小さい外れ値の影響を受けにくい（ロバストな）性質があります。
- **最頻値 (Mode)**: 最も頻繁に現れる値（度数分布表では度数が最大の階級値）。

## 散布度 (Dispersion)
データが中心からどれくらい散らばっているか（ばらつきの大きさ）を示す指標です。

- **分散 ($s^2$)**: 各データと平均値との差（偏差）を2乗し、その平均をとったもの（標本分散）。
    - *※母集団の分散は $\sigma^2$ と表します。母集団の分散を標本から偏りなく推定する推測統計では、データ数から1を引いた $n-1$ で割る「不偏分散」を使います。*
- **標準偏差 ($s$)**: 分散の正の平方根（母標準偏差は $\sigma$）。2乗によって変わってしまった単位を元に戻し、実際のデータと同じ単位で散らばり具合を把握できます。
- **範囲 (Range)**: 最大値から最小値を引いた差。大まかな全体の広がりを最も簡単に掴めます。
- **四分位範囲 (IQR) と 四分位偏差**: データを4等分した第3四分位数と第1四分位数の差（$IQR = Q_3 - Q_1$）。外れ値を除いた中心50%のデータの広がりを表します。なお、四分位偏差は $IQR / 2$ です。
- **変動係数 (CV)**: 標準偏差を平均値で割った比率（$CV = s / \bar{x}$）。身長と体重のように測定単位が異なるデータ同士や、平均値の桁数が大きく違うグループ同士で「相対的なばらつきの大きさ」を比べる際に役立ちます。

## 分布の形状・不平等度
データの山や裾の広がり方、あるいは偏りの度合いを捉える指標です。

- **歪度 (Skewness)**: 分布の左右非対称性を表す指標。右側に長い裾野が伸びている場合は正（プラス）、左側に裾野が伸びている場合は負（マイナス）の値をとります。
- **尖度 (Kurtosis)**: 正規分布を基準としたときの、分布の中心の尖り具合（または裾の重さ）を表す指標。
- **ローレンツ曲線とジニ係数**: 所得や富などの偏り（不平等度）を可視化・定量化する指標。ジニ係数は0（完全な平等）から1（完全な不平等）までの値をとり、0に近いほど均等に分布していることを示します。
