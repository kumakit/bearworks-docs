# 2変数記述統計

2つの変数（属性）に注目し、両者の間にどのような関係性（相関や連関）があるかを要約・分析する手法です。

## 量的データの関係（相関）
身長と体重のように、数値で測定される連続量同士の直線的なつながりを調べます。

- **散布図**: 縦軸と横軸に2つの変数 $x, y$ をとってデータをプロットしたグラフ。関係の傾向（正・負の相関）や外れ値の有無を一目で直感的に掴むことができます。
- **共分散 ($S_{xy}$)**: 2つの変数の偏差を掛け合わせた値の平均値。正の相関か負の相関かという「向き」は分かりますが、数値の大きさが元の単位に左右されるため、関係の「強さ」を直接比べることはできません。
- **相関係数 (ピアソンの積率相関係数, $r$)**: 共分散をそれぞれの標準偏差の積で割って無次元化した値。単位の影響を受けずに直線的な関係の強さを客観的に測ることができます。値は必ず $-1 \le r \le 1$ の範囲に収まります。
$$
r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}}
$$
- **順位相関係数 (スピアマンの $\rho$)**: 数値そのものではなく「順位（ランキング）」を使って計算する相関係数。データが順序尺度である場合や、直線的ではないものの「片方が増えればもう片方も増える」といった単調な関係を調べたい場合に有効です。

## 質的データの関係（連関）
性別や血液型、アンケートの満足度区分など、カテゴリごとの分類データ同士の結びつき（連関）を調べます。

- **分割表（クロス集計表）**: 2つのカテゴリ変数の組み合わせごとに、該当するデータの度数を格子状にまとめた表。
- **クラメールの連関係数 / ファイ係数**: 分割表をもとに計算されるカイ二乗（$\chi^2$）統計量をベースに、カテゴリ間の関連の強さを $0 \sim 1$ で表した指標。

## 単回帰分析の基礎
一方の変数（説明変数 $x$）をもとに、もう一方の変数（目的変数 $y$）の値を予測・説明する手法です。

- **回帰直線 ($y = \hat{\beta}_0 + \hat{\beta}_1 x$)**: データ点とのズレ（残差）の2乗和が最も小さくなるように引いた直線（最小二乗法）。$\hat{\beta}_1$ は傾き（回帰係数）、$\hat{\beta}_0$ は切片を表します。
- **決定係数 ($R^2$)**: 引いた回帰直線が実際のデータをどれくらい正確に説明できているかを示す指標（モデルの当てはまりの良さ）。単回帰分析の場合、ピアソンの相関係数の2乗（$r^2$）と一致します。
